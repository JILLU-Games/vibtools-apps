# Project Technical Knowledge Base (`project/`)

> **Notice:** This directory is tracked in Git and serves as the single source of internal technical truth for the entire codebase.

---

## 🎯 Purpose & Objectives (উদ্দেশ্য ও প্রয়োজনীয়তা)

এই ফোল্ডারে প্রজেক্টের যাবতীয় কারিগরি খুঁটিনাটি (internal technical architecture, logic, functions, components, modules) বিস্তারিতভাবে নথিবদ্ধ থাকবে। প্রজেক্টের "নাড়িভুঁড়ি" ও ব্যাকবোন বুঝতে এটি তৈরি করা হয়েছে।

### Core Inclusions (যা যা এখানে বাধ্যতামূলকভাবে থাকবে):
1. **Functions & Logic Registry:** প্রতিটি ফাংশন কোনটি কী কাজে লাগে, কোন লজিকটি কোথায় অবস্থান করছে, কেন ব্যবহার করা হয়েছে।
2. **File & Component Architecture:** কোন ফাইলটির কাজ কী, কোনটি কীভাবে সেটআপ করা, কোন ফাইল কোথায় আছে।
3. **Module & Dependency Rationales:** কোন মডিউল কেন ব্যবহার করা হয়েছে, কোনটি কোথায় লাগবে, কখন কীভাবে ব্যবহৃত হয়েছে।
4. **Real-time Feature & Code Sync:** প্রতিটি ফিচার বা পেজের বিস্তারিত বিবরণী। কোডে যেকোনো আপডেট, চেঞ্জ, ফিক্স বা নতুন কিছু যোগ করার সাথে সাথে সংশ্লিষ্ট ফাইল এখানে আপডেট করা হবে।
5. **Implementation Logs:** প্রজেক্টে কখন কী আপডেট বা ফিক্স কার্যকর হলো, তার ধাপভিত্তিক হিস্টোরি ও লগ।

## 📁 Directory Structure (ফোল্ডার গঠন)

```text
project/
├── README.md              # প্রজেক্ট টেকনিক্যাল বেসের বিবরণ ও নিয়মাবলী
├── MANIFEST.md            # প্রজেক্ট ডিরেক্টরির ফাইল ও সাব-ফোল্ডার ইনডেক্স
├── MINIFEST.md            # ম্যানিফেস্ট রেফারেন্স ফাইল
├── architecture/          # হাই-লেভেল সিস্টেম আর্কিটেকচার, ডেটা ফ্লো ও সেটআপ গাইড
├── features/              # প্রতিটি ফিচার ও পেজের পুঙ্খানুপুঙ্খ বিবরণ
├── functions/             # প্রতি ফাংশন, এপিআই হ্যান্ডলার ও লজিকের কাজের ব্যাখ্যা
├── modules/               # ব্যবহৃত মডিউল ও লাইব্রেরির প্রয়োজনীয়তা ও ব্যবহার
└── logs/                  # আপডেট ও ফিক্সের ধাপভিত্তিক লাইভ চেঞ্জলগ
```

## 📋 Strict Rules for Agents (এজেন্টদের জন্য অবশ্য পালনীয় নিয়ম)

- **Mandatory Live Sync:** যখনই সোর্স কোডে (`functions/`, `public/`, কনফিগ ইত্যাদি) কোনো চেঞ্জ, অ্যাড, ডিলিট বা ফিক্স করা হবে, তখনই তৎক্ষণাৎ `project/` এর সংশ্লিষ্ট ডকে আপডেট দিতে হবে।
- **Deep Technical Accuracy:** কোনো ফাংশন বা লজিক কেন লেখা হয়েছে, কোথায় ব্যবহৃত হয়েছে এবং কীভাবে রান করে তা কোনো অনুমান ছাড়াই নির্ভুলভাবে লিখে রাখতে হবে।
- **Manifest Maintenance:** যেকোনো নতুন ফাইল তৈরি হলে `project/MANIFEST.md` এ তার ট্র্যাক এন্ট্রি যোগ করতে হবে।
